谷歌文档翻译 · 无痕多开 v1.4.0

安装（仅首次需要）
1. 如果拿到 ZIP，先完整解压到一个固定文件夹。
2. 打开 Chrome，在地址栏输入：chrome://extensions
3. 打开右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择本说明所在的文件夹。
   应选到直接包含 manifest.json 的那一层，不是 ZIP 文件。
5. 点击 Chrome 右上角拼图图标，将「谷歌文档翻译 · 无痕多开」固定到工具栏。

文件夹模式：按顺序放入不同文档，可自动点击翻译
1. 在扩展「详情」中开启「在无痕模式下启用」，允许访问谷歌翻译网站。
2. 点击扩展图标，再点击「选择文件夹，按序放入文档」。
3. 在新页面点击「选择文件夹」，选择文档目录。
4. 查看排序列表并选择目标语言，需要自动翻译时勾选「按顺序自动点击『翻译』」。
5. 点击「打开 N 页并自动翻译」。未勾选时，按钮为「打开 N 页并放入文档」。
6. 文件夹页面显示各文档的放入、点击状态。点击「查看翻译窗口」查看翻译进度和结果。

自动点击说明
• 首次默认不勾选，以后记住上次开始任务时的选择。
• 文档就绪后，严格按列表顺序逐页点击「翻译」，相邻点击至少间隔 2 秒。
• 前面的文档尚未就绪时，后面的文档会等待；失败项跳过并显示原因。
• 不等待上一份翻译完成才点击下一页，因此不同文档可以同时翻译。
• 点击「停止自动点击」停止后续操作；已经发出的当前点击指令可能仍会执行。
• 「已点击翻译」表示按钮已点击，翻译是否完成请在谷歌页面查看。下载译文需手动操作。
• 点击结果不确定时显示「点击结果待确认」，不会自动重复提交，请到对应页面核对。
• 未勾选时仅放入文档，由你在各页点击「翻译」。

• 按文档实际数量打开标签页，每份文档一页，不受普通模式的数量设置限制。
• 文件名按自然顺序排列，例如文档1、文档2、文档10；子文件夹按相对路径排序。
• 默认只处理目录中的直接文件，需要子文件夹时勾选「包含子文件夹」。
• 支持 PDF、DOCX、PPTX、XLSX，每份不超过 10 MB。
• 空文件、临时文件、不支持的格式和过大的文件会跳过，并显示原因。
• 放入和自动点击完成前请保持文件夹页面打开，文件临时保留在该页面中。
• 失败项可点击「重新打开失败项」重试；原来的标签页保留。
• 谷歌翻译仍会校验文件内容，例如 PDF 最多 300 页。

普通模式：打开空白文档翻译页
点击扩展图标 → 输入并选择目标语言 → 设置打开数量 → 点击打开按钮。
数量可以手动输入，也可以用数字框的上下箭头调整，范围为 1–100 的整数。
可以输入中文名称、外文名称或代码，例如「德语」「Deutsch」「German」「de」。
输入时会筛选语言；点击结果或按回车选中，也可以点击输入框右侧箭头浏览全部语言。
方向键可以切换匹配结果；输入无效或有多个匹配时，需要先选择具体语言。
首次默认为德语、10 个标签页，以后记住上次使用的语言和数量。内置 64 种语言。
每次点击创建一个新的无痕窗口，其中包含你指定数量、相同目标语言的文档翻译标签页。
所有页面原文均设为「自动检测」，界面语言为简体中文，直接进入「文档」模式。
德语示例：https://translate.google.com/?hl=zh-cn&sl=auto&tl=de&op=docs
打开之后，在各个标签页中选择需要翻译的文档。

无痕窗口中的扩展入口（可选）
从普通 Chrome 窗口点击本扩展即可创建无痕窗口。
如果还要在无痕窗口的工具栏中使用它，进入本扩展「详情」，
打开「在无痕模式下启用」，然后重新点击扩展图标。

常见问题
• 每次都会新建窗口；重复点击不会向原来的无痕窗口追加标签页。
• 页面能打开但加载失败：请检查当前网络能否访问 translate.google.com。
• Chrome 已被管理策略禁止使用无痕模式时，扩展会显示失败提示。
• 普通模式打开空白翻译页；文件夹模式自动放入文件，可选按顺序自动点击「翻译」。
• 加载后请保留文件夹。修改代码后，在 chrome://extensions 中点击该扩展的刷新按钮。

权限与数据
storage：保存语言、普通模式数量、自动点击选项，以及本次浏览器会话内的文档分配和点击状态。
谷歌翻译网站访问：在对应翻译标签页中放入你选择的文件，并按你的选项点击「翻译」。
点击翻译后，文档会提交给谷歌翻译服务处理。
文件内容由文件夹页面临时读取和传递，不写入扩展的持久存储。
无账号、无 API Key、无第三方服务器。
这是独立的个人工具，并非 Google 官方扩展。

从旧版本更新
如果已加载本文件夹，在 chrome://extensions 中点击本扩展的刷新按钮即可。
如果在另一文件夹安装，请先用新版文件覆盖原文件，再刷新扩展。
更新后请关闭旧的文件夹页面，从扩展入口重新打开并选择文件夹。
如 Chrome 提示新增网站权限，请启用扩展并允许访问谷歌翻译。
使用文件夹模式前，打开扩展详情并开启「在无痕模式下启用」。
