# 开发过程记录

记录日期：2026-09-11。归档版本：v1.4.0。

本文根据本次协作中的需求、代码和测试记录整理，用来说明功能如何逐步形成；不是逐字聊天转录，也不代表已经保存了早期版本的完整源码快照。

## 需求演变

| 阶段 | 需求 | 最终处理 |
| --- | --- | --- |
| 初始入口 | 一键打开谷歌浏览器无痕窗口，选择目标语言后一次打开 10 个文档翻译标签页 | 使用 Chrome 工具栏扩展，创建独立无痕窗口 |
| 语言选择 | 可以手动输入选择语言 | 支持中文、外文、英文名称和语言代码检索，提供鼠标和键盘选择 |
| 数量设置 | 可以选择打开几个标签页 | 普通模式支持 1–100，记住上次的设置 |
| 同一文件复制 | 第一页选择文件，后续页使用同一文件 | 用户随后取消，此需求未作为最终功能实现 |
| 文件夹导入 | 文件夹里的文档按顺序依次放入各个标签页 | 按文件名自然排序，一份文件对应一个标签页，可选递归子目录 |
| 文档数量优先 | 文档数超过设置的标签页数时怎么办 | 按用户选择，以文档实际数量开页，不受普通模式数量设置限制 |
| 自动点击 | 按顺序自动点击翻译按钮 | 新增可选自动点击，等待对应文档就绪，间隔至少 2 秒，支持停止 |
| GitHub 归档 | 上传源码、安装包和开发过程 | 以当前 v1.4.0 成果建立私有仓库 |

## 实现分工

- `popup.mjs` / `launcher.mjs`：工具栏弹窗、语言与数量设置、普通无痕窗口创建。
- `language-picker.mjs` / `languages.mjs`：语言数据、检索、候选列表和输入法处理。
- `folder.mjs`：文件夹管理页面，保留用户选择的 File 对象，展示顺序、状态和操作按钮。
- `folder-files.mjs`：过滤文件、自然排序、确定类型和分块编码。
- `folder-broker.mjs`：扩展后台协调标签页分配、文件块读取和点击请求。
- `document-loader.js`：在被分配的谷歌标签页内放入指定文档、确认就绪、点击文档翻译按钮。
- `translation-queue.mjs`：按列表顺序调度点击；失败项跳过；停止后不发起后续点击。

扩展使用 Manifest V3，后台是 service worker。文档分配与点击结果保存在当前浏览器会话中，文件内容不进入持久存储。

## 开发中遇到的问题

### 1. 页面上同时存在图片与文档上传控件

谷歌翻译页面有不止一个文件输入框。只选第一个 `input[type=file]` 可能选中图片控件。最终依据文件输入框的接受类型寻找 PDF/DOCX 文档上传控件，测试也核对图片输入框没有收到文件。

### 2. 输入框出现时，谷歌的事件处理程序可能还没就绪

立即触发 change 事件并不总能让页面接收文档。最终在输入后等待页面显示文件名；必要时有限次重发事件，并在超时后显示明确失败信息。

### 3. 文件需要可靠跨页面传递

管理页以 192 KiB 为单位读取并编码，后台仅把文件分块传给分配的无痕标签页，内容脚本重建 File 对象。测试使用 SHA-256 校验小文件和跨多个块的文件内容一致。

### 4. 网页就绪顺序与文件顺序不同

多个标签页加载速度不同。点击队列只处理当前顺序位置的文档，前面的文档仍在加载时等待，避免后面的页面抢先点击。

### 5. 网址参数变化不能单独证明离开了文档模式

真实测试发现 Google 会把 `op=docs` 改写为 `op=translate`，但仍显示文档翻译界面。先前只检查网址参数的判断会误报。修复后结合目标语言、当前选中的「文档」模式以及指定文件名确认页面状态，再查找可见且可用的「翻译」按钮。

### 6. 点击结果中断时可能发生重复提交

后台先记录已发送的点击尝试，再发送到内容脚本。收到结果后记录已点击或失败；返回中断则标记待确认。即使 service worker 重启，也不会自动重复发送已尝试的指令。

## v1.4.0 的行为边界

- 自动点击首次默认关闭，以后记住上次启动时的选择。
- 按顺序点击，间隔至少 2 秒，不等待前一份翻译完成。
- 「停止自动点击」停止后续指令，已经发出的当前指令可能仍执行。
- 只报告导入和点击状态，翻译进度、结果及下载由谷歌页面提供。
- 文件夹管理页关闭或刷新后需要重新选择文件夹。
- 实际翻译仍受谷歌网页当前支持的文件类型、大小和内容限制影响。

## 验证结论

20 项单元测试通过；普通模式、手动文件夹模式、自动点击、停止功能的浏览器检查通过；3 份示例 PDF 在真实谷歌翻译页按 1、2、10 顺序点击，间隔约 2 秒。具体证据和复现命令见 [TESTING.md](TESTING.md)。
